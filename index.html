3. Comprendre le résultat

Si le modèle français n'est pas compatible, le laboratoire l'indiquera explicitement : il ne remplacera jamais silencieusement le français par un modèle anglais. La conversion ONNX nécessiterait une étape technique supplémentaire sur ordinateur.

Aucune note n'est envoyée à un service OCR. La vérification interroge uniquement les fichiers publics du modèle. Un éventuel modèle compatible serait téléchargé et exécuté dans le navigateur.

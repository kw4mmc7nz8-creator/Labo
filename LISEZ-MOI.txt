MesListes — Labo4, 15 novembre 2026

But : vérifier si le modèle TrOCR français dj0w/trocr-french-handwriting-v5 est utilisable directement dans Safari iPhone avec Transformers.js.

Installation : déposer index.html à la racine d'un dépôt GitHub Pages indépendant.

Ce laboratoire est un test de faisabilité, pas un OCR français garanti. Il vérifie d'abord les fichiers ONNX disponibles sur Hugging Face. Si aucun n'est présent, il explique qu'une conversion est nécessaire. Il ne bascule pas vers un modèle anglais.

MesListes n'est pas modifiée. Aucun abonnement, aucune clé API.

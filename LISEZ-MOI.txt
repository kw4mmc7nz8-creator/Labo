Laboratoire de reconnaissance manuscrite MesListes — TrOCR

1. Créer un nouveau dépôt public GitHub Pages (par exemple MesListes-Labo).
2. Déposer index.html à la racine du dépôt.
3. Dans Settings > Pages, choisir Deploy from a branch, main, /(root).
4. Ouvrir l'adresse GitHub Pages sur l'iPhone dans Safari.
5. Écrire un mot puis toucher Reconnaître.

ATTENTION : cette expérience ne remplace PAS MesListes et ne doit pas être déposée dans le dépôt MesListes existant.
Le premier chargement télécharge une bibliothèque JavaScript et les poids d'un modèle d'IA, potentiellement plusieurs dizaines à centaines de Mo. Le chargement peut échouer sur iPhone pour des raisons de mémoire, de compatibilité ou de réseau.
Le modèle TrOCR Small Handwritten est principalement entraîné sur de l'anglais. La qualité pour les mots français n'est pas garantie.
Les traits restent dans la page ; l'inférence est prévue dans le navigateur, sans API distante de reconnaissance. Les composants et poids sont téléchargés depuis des CDN / Hugging Face.
L'archive contient la page du laboratoire, mais pas le modèle volumineux téléchargé au moment du test.
